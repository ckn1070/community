# Spike 작업 문서 목록

Spike는 구현을 시작하기 전 제한 시간 안에 기술 불확실성을 줄이는 조사입니다.

- 확인할 질문과 성공·중단 기준을 먼저 적습니다.
- 제한 시간을 정합니다.
- 결과 정의가 닫히기 전에는 대안·실험 방법·결론을 미리 쓰지 않고 [작업 문서 생명주기](../100-work-item-lifecycle.md#계획-단계와-최소-artifact)를 따릅니다.
- production 구현을 Spike 결과에 섞지 않습니다.
- 결론과 폐기할 실험 자산을 명확히 합니다.
- 새 Spike는 생성 연도 디렉터리를 만들고 `001`부터 현재 읽기 순서에 맞춰 번호를
  붙입니다.
- 현재 등록된 Spike 문서는 없습니다.
