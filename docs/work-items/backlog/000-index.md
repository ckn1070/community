# Backlog 문서 목록

이 디렉터리는 아직 착수하지 않은 기능 아이디어와 나중에 작업할 때 참고할 고민을 보관합니다.

## 작성 기준

- backlog는 확정 요구사항이 아니라 초안 아이디어입니다.
- 현재 작업 완료를 막는 결정은 backlog에 두지 않고 활성 작업 문서의 `남은 결정`에 둡니다.
- 실제 작업을 시작하면 backlog의 필요한 내용을 새 작업 문서로 옮깁니다.
- 새 작업 문서로 모두 옮기거나 폐기한 뒤 backlog를 `Closed`로 바꾸고, 상단 `결과`에 전환·폐기 처분, 새 owner와 남은 활성 책임이 없음을 기록합니다. 상세 계획은 새 owner만 소유합니다.

## 파일명 기준

작업 문서는 생성 연도 디렉터리에 두고 현재 문서의 읽기 순서에 따라 `001`부터
빈자리 없이 번호를 붙입니다.

```text
2026/001-example-backlog.md
```

## 현재 문서

- [2026/000-index.md](2026/000-index.md): 2026년 backlog 문서 목록입니다.
