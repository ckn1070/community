# AutoSquare 신차 탐색 및 커뮤니티 제품 후보

## 상태

Open

## 배경

AutoSquare는 사용자가 신차 정보를 탐색하고 AI 추천, 검증된 리뷰·커뮤니티와 위치 기반 대리점 정보를 통해 구매 결정을 내릴 수 있게 하는 제품 후보입니다. 이 문서는 아직 확정되지 않은 MVP 후보를 한곳에서 검토하고, 실행 가능한 단위만 별도 작업과 제품 SOT로 승격하기 위해 존재합니다.

현재 repository와 제품 SOT의 제품명은 `Carmunity`입니다. `AutoSquare`가 Carmunity의
리브랜딩·향후 제품 방향인지, 별도 제품인지 아직 결정되지 않았습니다. 이 관계가 먼저
확정되기 전에는 아래 후보를 Carmunity 요구사항이나 roadmap으로 적용하지 않습니다.

## 문서 성격

이 문서는 확정된 제품 기준이나 구현 요구사항이 아니라 초기 MVP 후보안입니다.
MVP 범위는 이후 논의에 따라 바뀔 수 있으며, 확정된 항목만 `product` 문서나 `features` 작업 문서로 승격합니다.

이 문서의 내용은 구현 시작 조건을 충족하지 않습니다.
실제 작업을 시작할 때는 목표, 범위, 제외 범위, 수용 기준, 구조 선택, 검증 기준을 새 작업 문서에서 다시 확정합니다.

Phase 1은 고품질 차량 정보와 신뢰도 높은 커뮤니티를 통해 진성 유저 트래픽을 확보하고, 구매 결정 단계에서 위치 기반 오프라인 대리점 연결을 제공하는 방향입니다.
지도 기반 대리점 찾기 기능을 우선 구상 중입니다.

Phase 2 이후에는 확보된 트래픽과 유저 데이터를 바탕으로 타겟팅 광고, 딜러 매칭 수수료, 차량 용품 이커머스 연동 같은 종합 모빌리티 수익 모델을 검토합니다.

## 확정 결정

- 현재 PRD는 완성된 제품 기준이 아니라 초창기 MVP 후보입니다.
- MVP 후보는 영구 제품 문서가 아니라 backlog에 먼저 보관합니다.
- MVP 전용 폴더는 지금 만들지 않고 단일 backlog 문서로 시작합니다.
- AutoSquare와 Carmunity의 관계는 미확정이며 두 이름을 동의어로 사용하지 않습니다.

## Backlog 항목

### 1. 차량 탐색 및 카탈로그

사용자가 이커머스 쇼핑몰에서 상품을 둘러보듯 신차를 탐색하는 기능 후보입니다.

- 브랜드, 차종, 가격대, 연료 타입, 연비 등 다중 필터 검색을 제공합니다.
- 차량 상세 페이지에서 내외부 이미지 갤러리, 트림별 기본/선택 옵션, 제원, 연비 정보를 제공합니다.
- 좋아요 또는 스크랩 버튼을 통해 개인 관심 차량 목록에 추가할 수 있습니다.
- 차량 2~3대를 선택해 가격, 제원, 유지비 등을 표 형태로 비교할 수 있습니다.

### 2. 실오너 인증 기반 커뮤니티

정보 신뢰도와 재방문율을 높이기 위한 커뮤니티 기능 후보입니다.

- 차종별 라운지, 자유게시판, 질문/답변, 출고 후기, 시승 후기 게시판을 제공합니다.
- 사용자는 마이페이지에서 차량등록증 또는 차량 구매 증명서 이미지를 업로드해 오너 인증을 신청할 수 있습니다.
- 관리자는 서류를 확인한 뒤 승인 또는 반려할 수 있습니다.
- 승인된 사용자는 닉네임과 프로필 옆에 차종 기반 오너 배지를 노출할 수 있습니다.

### 3. AI 스마트 컨설턴트

사용자 상황을 종합해 차량 추천과 비교를 돕는 LLM 기반 상담 기능 후보입니다.

- 화면 우측 하단 플로팅 버튼 또는 별도 AI 상담 탭에서 채팅 인터페이스로 진입합니다.
- 예산, 사용 목적, 가족 구성, 캠핑 같은 라이프스타일 정보를 바탕으로 차량을 추천합니다.
- 커뮤니티 글을 바탕으로 특정 차량의 이슈나 여론을 요약할 수 있습니다.
- 대화 중 차량 비교를 요청하면 텍스트 답변과 함께 미니 비교표 UI를 제공할 수 있습니다.

### 4. 위치 기반 딜러/대리점 매칭

플랫폼 안에서 구매 의향이 생긴 사용자를 오프라인 구매처로 연결하는 기능 후보입니다.

- 차량 상세 페이지 또는 견적/비교 이후 `이 차량 상담/구매하러 가기` 같은 진입점을 제공합니다.
- 사용자의 현재 위치나 입력한 거주지를 기반으로 가까운 공식 대리점과 구매처를 지도와 목록으로 보여줍니다.
- 전화 걸기, 영업시간 확인, 길 찾기 연동을 제공합니다.

### 5. 마이페이지

개인화와 활동 이력 관리를 위한 기능 후보입니다.

- 내 차고에서 좋아요 또는 스크랩한 차량 목록을 확인합니다.
- 내가 작성한 커뮤니티 글, 댓글, AI 상담 이력을 확인합니다.
- 오너 인증 서류 제출 상태와 심사 진행 상태를 확인합니다.

### 6. 관리자 기능

Phase 1 기능을 운영하기 위한 관리자 기능 후보입니다.

- 회원과 콘텐츠를 관리하고, 신고 글 처리와 유저 제재를 수행합니다.
- 신차 출시 시 제원, 이미지, 가격표를 갱신할 수 있는 차량 데이터 CMS를 제공합니다.
- 오너 인증 서류를 열람하고 승인 또는 반려 사유를 입력합니다.

### 7. Phase 2 이후 확장

초기 MVP 이후의 수익화와 확장 후보입니다.

- 제휴 딜러들이 유저에게 직접 견적을 제시하는 B2B 딜러 매칭 또는 역경매 시스템을 검토합니다.
- 유저가 조회하는 차종에 맞춘 보험, 타이어, 튜닝 용품 광고와 스폰서십을 검토합니다.
- 커뮤니티 기반 차량 용품 이커머스 탭을 검토합니다.

## 사용자 핵심 여정 후보

1. 사용자가 플랫폼에 접속해 신차 이미지를 둘러보고 관심 있는 차량을 검색하거나 스크랩합니다.
2. 어떤 차를 살지 고민될 때 AI 상담을 호출해 예산과 상황을 입력하고 추천을 받습니다.
3. 추천받은 차량을 비교 기능으로 상세 제원과 예상 비용 관점에서 대조합니다.
4. 커뮤니티에서 오너 인증 배지를 단 실제 소유주의 후기와 답변을 확인합니다.
5. 구매 결심 단계에서 지도 기반 대리점 정보를 확인하고 방문 또는 전화 상담으로 이어집니다.
6. 차량 구매 후 본인도 오너 인증을 받고 출고기와 리뷰를 작성해 커뮤니티 신뢰도를 높입니다.

## 전환 기준

- 특정 기능을 실제로 구현하기로 결정하면 이 문서의 관련 항목을 새 `features` 작업 문서로 옮깁니다.
- 먼저 AutoSquare와 Carmunity의 관계를 확정합니다. 별도 제품이면 이 repository의
  `features`로 승격하지 않습니다.
- 기술 가능성, 비용, 외부 서비스 선택이 먼저 필요하면 새 `spikes` 작업 문서로 옮깁니다.
- 제품 방향으로 확정된 내용만 `docs/product` 문서로 승격합니다.
- 도메인 용어와 업무 규칙으로 확정된 내용만 `docs/domain` 문서로 승격합니다.
- 모든 항목이 작업 문서로 전환되었거나 폐기되면 이 backlog를 `Closed`로 바꿉니다.
