# 기능 작업 문서 목록

기능 문서는 신규 제품 기능의 현재 계획 단계 또는 구현 결과를 소유합니다.

- 현재 작업: [2026 기능 작업](2026/000-index.md)
- 상태와 계획 단계 또는 현재 결과는 본문 상단에서 확인합니다.
- 단계별 최소 artifact, 조건부 `-design`과 rollback은 [작업 문서 생명주기](../100-work-item-lifecycle.md#계획-단계와-최소-artifact)를 따릅니다.
- 완료된 장기 정책은 domain, project, tech-stack에 승격합니다.
