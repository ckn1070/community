# 버그 작업 문서 목록

버그 문서는 재현 가능한 기대 동작과 실제 동작의 차이, 원인, 수정 결과, 회귀 검증을 소유합니다.

- Proposed·Planned는 `상태`와 `계획 단계`, In Progress·Blocked·Done은 `결과`를 둡니다.
- 결과를 바꾸는 원인 경계와 실제 수정 계획은 [작업 문서 생명주기](../100-work-item-lifecycle.md#계획-단계와-최소-artifact)에 따라 서로 다른 단계에서 작성합니다.
- 기능 요구 변경은 버그로 숨기지 않고 feature 또는 improvement로 분리합니다.
- [2026 버그](2026/000-index.md): 현재 확인된 기대 동작과 실제 동작의 결함

계획 lifecycle 기준: [공통 계획·설계 템플릿](../templates/000-index.md)
