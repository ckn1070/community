# 버그 작업 문서 목록

버그 문서는 재현 가능한 기대 동작과 실제 동작의 차이, 원인, 수정 결과, 회귀 검증을 소유합니다.

- Proposed·Planned는 상태 다음에 `달성할 결과`, In Progress·Blocked·Done은 `결과`를 둡니다.
- 원인 분석과 수정 계획을 분리합니다.
- 기능 요구 변경은 버그로 숨기지 않고 feature 또는 improvement로 분리합니다.
- [2026 버그](2026/000-index.md): 현재 확인된 기대 동작과 실제 동작의 결함
