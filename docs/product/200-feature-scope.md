# 기능 범위

이 문서는 제품 관점의 기능 영역과 현재 우선순위 경계를 정리합니다.
구현 계획과 진행률은 work item이 소유합니다.

## 제품 기능 영역

- 자동차 브랜드, 모델, 세대, 트림, 제원, 옵션, 가격 조회
- 자동차 상세 정보
- 차량과 연결하지 않고 시작하는 일반 커뮤니티
- 일반 커뮤니티와 자동차 정보의 후속 연결
- 게시글 목록과 상세
- 댓글, 반응, 북마크
- 회원 공개 profile
- 신고, 숨김, 제재
- 이미지 업로드와 보관
- 인증, 계정 복구, 관리자 운영 기반

## 현재 구현된 기반

현재 backend에는 다음 제품 기반이 구현되어 있습니다.

- 일반 회원 가입과 이메일 인증
- 비밀번호 로그인, refresh, logout
- 비밀번호 변경과 재설정
- 최초 최고 관리자 bootstrap
- 관리자 초대 생성, 수락, 회수
- role과 session 기반 API 접근
- 인증·인가 감사 이벤트

상세 결과는 [2026 기능 작업 문서](../work-items/features/2026/000-index.md)를 확인합니다.

## 현재 일반 커뮤니티 경계

현재 도입 대상은 차량 정보와 연결하지 않고 독립적으로 사용할 수 있는 일반 커뮤니티입니다.
정확한 핵심 제품 범위는 [016 차량 비연결 일반 커뮤니티 결과 정의](../work-items/features/2026/016-general-community.md)가
소유합니다.

차량 관계와 아직 선택하지 않은 추가 커뮤니티 기능은 현재 범위가 아닙니다. 이후 도입할 때는
일반 커뮤니티를 차량 전용 기능으로 교체하지 않고 기존 핵심과 함께 존재하는 확장으로 다룹니다.

## 아직 작업으로 확정되지 않은 영역

자동차 카탈로그, 일반 커뮤니티의 차량 연결, 아직 선택하지 않은 커뮤니티 부가 기능,
신고·제재 정책, media 보관 정책과 중고차 확장 방식은 현재 작업 범위가 아닙니다. 이 항목은
영구 도메인 규칙이나 project module 결정으로 미리 승격하지 않습니다.
