# 기능 범위

이 문서는 제품 관점의 기능 영역과 현재 우선순위 경계를 정리합니다.
구현 계획과 진행률은 work item이 소유합니다.

## 제품 기능 영역

- 자동차 브랜드, 모델, 세대, 트림, 제원, 옵션, 가격 조회
- 자동차 상세 정보
- 차량과 연결하지 않고 시작하는 일반 커뮤니티
- 일반 커뮤니티와 자동차 정보의 후속 연결
- 게시글 목록과 상세
- 댓글, 반응, 북마크
- 회원 공개 profile
- 신고, 숨김, 제재
- 이미지 업로드와 보관
- 인증, 계정 복구, 관리자 운영 기반

## 현재 구현된 기반

현재 backend에는 다음 제품 기반이 구현되어 있습니다.

- 일반 회원 가입과 이메일 인증
- 비밀번호 로그인, refresh, logout
- 비밀번호 변경과 재설정
- 최초 최고 관리자 bootstrap
- 관리자 초대 생성, 수락, 회수
- role과 session 기반 API 접근
- 인증·인가 감사 이벤트

상세 결과는 [2026 기능 작업 문서](../work-items/features/2026/000-index.md)를 확인합니다.

## 자동차 카탈로그 현재 범위

자동차 카탈로그는 로그인 없이 브랜드, 모델 목록과 모델 상세를 읽는 기능입니다. 현재·예정·
단종 차량을 같은 모델 기준으로 탐색하고 다음 정보를 제공합니다.

- 브랜드·모델·세대·시장별 모델 연식
- 차체·인승·주요 치수·중량·휠·타이어와 동력계통·주요 장치
- 실제 판매 트림, 기준일 기본 가격·선택 품목과 조건별 인증값
- 표시용 기본 품목·보증·안전도와 권리가 확인된 media

모델 목록은 검색어, 브랜드, 차체, 동력 형식, 연료, 가격대, 판매 상태, 기준일, 정렬과 page를
선택 입력으로 받습니다. 모든 filter는 같은 판매 구성을 기준으로 적용합니다. 상세 업무 의미는
[130 자동차 카탈로그 도메인](../domain/130-car-catalog.md), 현재 관계형 구조는
[110 자동차 카탈로그 Schema Reference](../project/schema/110-car-catalog.md)가 소유합니다.

사용자가 카탈로그에 처음 들어오면 검색어나 filter 선택을 기다리지 않고 서울 현재 날짜의
판매 중 모델 첫 page를 이름순으로 보여줍니다. 브랜드 선택지는 같은 시점에 독립적으로 읽으며,
브랜드 목록이 먼저 끝나야 모델 목록을 조회할 수 있는 구조가 아닙니다. 초기 목록은 인기·추천
차량을 별도로 선별한 결과가 아니라 전체 브랜드의 판매 중 모델을 기본 조건으로 조회한 결과입니다.
모델마다 여러 연식이 있으면 목록의 한 카드에는 현재 조회 조건에서 선택한 대표 연식을 표시합니다.

구현 상태와 다음 단계는
[016 신차 카탈로그 schema·조회 API](../work-items/features/2026/016-new-car-catalog-query-api.md)에서
확인합니다.

대표 fixture는 제품에 제공할 production catalog data를 대신하지 않습니다. 공식 자료에
근거한 실제 데이터의 공개 범위·검수·적재는
[017 자동차 카탈로그 초기 데이터 구축](../work-items/features/2026/017-car-catalog-initial-data.md)의
독립된 제품 데이터 작업입니다.

## 현재 일반 커뮤니티 경계

현재 도입 대상은 차량 정보와 연결하지 않고 독립적으로 사용할 수 있는 일반 커뮤니티입니다.
정확한 핵심 제품 범위는 [018 차량 비연결 일반 커뮤니티](../work-items/features/2026/018-general-community.md)가
소유합니다.

현재 범위에는 게시글 본문 이미지의 안전한 업로드·노출·연결·미사용 정리·삭제 뒤 처리와
사용자 신고·관리자 숨김의 최소 운영 기능이 포함됩니다. 댓글·답글 미디어, 영상·일반 파일,
신고 사유 체계·계정 제재·복구·이의제기·보존 기간 같은 상세 정책은 포함하지 않습니다.

차량 관계와 아직 선택하지 않은 추가 커뮤니티 기능은 현재 범위가 아닙니다. 이후 도입할 때는
일반 커뮤니티를 차량 전용 기능으로 교체하지 않고 기존 핵심과 함께 존재하는 확장으로 다룹니다.

## 아직 작업으로 확정되지 않은 영역

일반 커뮤니티의 차량 연결, 아직 선택하지 않은 커뮤니티 부가 기능,
현재 최소 운영 범위를 넘는 신고·제재 정책, 게시글 이미지를 넘는 범용 media 정책과 중고차
확장 방식은 현재 작업 범위가 아닙니다. 이 항목은 영구 도메인 규칙이나 project module
결정으로 미리 승격하지 않습니다.
